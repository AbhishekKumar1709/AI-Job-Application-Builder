directory will hold plain-language, step-by-step guides for end users as

- Selecting templates
- Using AI optimization
- Checking ATS compatibility
- Creating cover letters
- Matching a resume to a job
- Managing resume versions
- Tracking applications
- Downloading resumes

A guide is added here only once the feature it describes actually works.
