# Project Overview

## What the product does (intent)

Helps a job seeker build resumes and cover letters, tailor them to specific
job postings, check ATS (applicant tracking system) compatibility, and track
applications — with AI assistance for optimization and generation.

**None of this is built yet.** This document describes the intended product;
see [PROJECT_STATUS.md](../PROJECT_STATUS.md) for what actually exists.

## Target users

Individual job seekers who want help writing and tailoring application
materials.

## Core problem

Writing a strong, ATS-compatible resume tailored to each job posting is slow
and easy to get wrong. The product aims to shorten that loop.

## Product positioning

A personal tool, not (currently) a multi-tenant SaaS product. No pricing,
teams, or org features are planned at this stage.

## Main user journeys (planned)

1. Build a master profile (work history, education, skills) once.
2. Generate a resume from a template using that profile.
3. Paste a job description; get tailoring/ATS suggestions.
4. Generate a matching cover letter.
5. Export to PDF.
6. Track the application's status over time.
